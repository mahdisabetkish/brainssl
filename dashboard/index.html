Two studies, one question

How far can structure and unlabelled data stretch a few annotations?

Brain tumour segmentation on multi-contrast MRI and autism classification from resting-state fMRI, each with a model built around a property of the data that the usual baseline ignores: the left-right symmetry of the brain, and the estimation noise of a connectome measured from a few minutes of signal.

Bilateral U-Net

MSD Task01 (BraTS): 750 scans, four contrasts each. Every encoder level can read the features of its mirror image across the midline, and the network is pretrained without labels by reconstructing hidden tissue from its contralateral twin.

Noise-aware connectome classifier

ABIDE I: 871 scans from 20 sites. Each scan's connectome is re-estimated on six sub-windows, and the classifier is trained on that spread rather than on one point per subject, which penalises connections that are not reproducible within a scan.

From raw download to this page

Reproduce

One Nextflow pipeline runs both studies, locally, in Docker or on a cluster; a test profile runs every stage on synthetic data in a few minutes.

Pipeline

Everything, one command

nextflow run mahdisabetkish/brainssl -profile docker,gpu

Or step by step

pip install -e .
brainssl download abide && brainssl download msd
brainssl prepare abide && brainssl prepare msd
python scripts/run_smri.py
python scripts/run_fmri.py
brainssl report

Inference without Python

brainssl-infer segment --model exports/segmentation \
  --input scan.nii.gz --output seg.nii.gz
